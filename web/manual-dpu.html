One DPU. From OS to HBN.

What is a DPU? A network adapter with its own Arm computer, memory, operating system and networking hardware. The server runs its host OS; the DPU runs a separate Arm OS. A BMC provides a separate management path.

Your goal

Understand each manual step before learning how DPF automates it. Identify where a command runs and what it changes.

Your outcome

A simulated DPU with a verified BFB-installed OS, checked HBN services, a tested sample route, restricted host access and working independent management.

Start: existing Arm Ubuntu, DPU mode, no HBN. All commands and output below are simulated. This lesson does not connect to your server or DPU. The BlueField-4 introduction is separate from this BlueField-3 procedure.

Order matters: DPU mode → BFB and Arm OS → HBN container → forwarding checks → host restrictions. HBN is itself a containerized service. A BFB installation alone does not make HBN operational.

Practice in the Linux-style console

Use Load command, then Run command, or type the displayed command. The terminal selector shows the machine you are working on. No file editing is required. Page reload starts a fresh exercise.
